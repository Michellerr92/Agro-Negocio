# Agro-Negocio
Sobre mi: 
Lidero equipos comerciales y técnicos en el sector de insumos agrícolas en Ecuador. 
Me apasiona unir el conocimiento del campo con los datos para tomar mejores decisiones sobre ventas, operaciones y desarrollo de talento.
Este espacio reúne mis proyectos de analítica y modelado de datos aplicados a problemas reales de negocio.

Gestión comercial y de operaciones en agroinsumos: venta directa y distribuidores
Diseño de esquemas de incentivos, presupuestos y seguimiento de KPIs
Tableros de ventas y cartera en Odoo ERP
Modelado y análisis de datos con SQL Server
